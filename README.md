# 🌲 Ashwood Survival

Ashwood Survival is a Unity-based survival game set in a forested wilderness. Players must gather resources, manage their health and energy, and craft tools to stay alive.

## 🚧 Features 

### 🏞 Player & Environment
- First-person camera controller.
- A vast map with paths, grassy hills, and mountains to explore!

### ✋ Interactable Objects & Basic AI
- Terrain with many interactable objects such as trees, bushes, logs, etc.
- Slimes that wander until they find the player and chase them down. Also interactable.

### 🎒 Inventory System
- 21 inventory slots.
- Tooltip and Description UI when hovering an item.
- Drag and drop feature for items in inventory.

### 🛠 Crafting System
- Crafting UI with categorized tabs for organization.
- 4 crafting recipes.
- Crafting recipes show required materials and quantities.
- The **“Craft”** button appears only when the player has enough materials.
- Upon crafting, materials are removed from the inventory and replaced with the new item.

### 🔋 Resource Bars: Health, Food, Hydration
- **Health Bar**: Red, max of 100 HP.
- **Energy Bar**: Yellow, max of 1000 EP. Depletes as the player moves.
- **Thirst Bar**: Blue. Depletes over time naturally.

### 🏡 Base Building
- Buildable Structures: Floors, Walls, Campfires
- Ghost preview system with green/red validity indicators.
- Snap-to-points for modular placement on ghosts of placed items.
- Construction mode can be canceled.
