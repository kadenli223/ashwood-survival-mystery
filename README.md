# 🌲 Ashwood Survival

Ashwood Survival is a Unity-based survival game set in a forested wilderness. Players must gather resources, manage their health and energy, and craft tools to stay alive.

## 🚧 Features (Check-In 3)

### 🛠 Crafting System
- Added a functional **crafting UI** with categorized tabs (e.g., Tools).
- Recipes show required materials and quantities.
- The **“Craft”** button appears only when the player has enough materials.
- Upon crafting, materials are removed from the inventory and replaced with the new item.

### 🔋 Resource Bars
- **Health Bar**: Red, max of 100 HP.
- **Energy Bar**: Yellow, max of 1000 EP. Depletes as the player moves.
- **Thirst Bar**: Blue. Depletes over time naturally.

### 🎒 Inventory Improvements
- More inventory slots added.
- Divider introduced to separate future **hotbar** items.
- UI adjustments for better clarity and usability.

## 🐞 Bug Fixes
- Fixed an issue where picking up an object near another overlapping one would collect both.
- Resolved a cursor-locking bug when closing the inventory with the crafting menu still open.
- Adjusted UI element alignment for resource bars to prevent misplacement as resources are depleted.
